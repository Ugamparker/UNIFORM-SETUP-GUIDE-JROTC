How to use the guide

  1. Select your service.
  2. Select the uniform type.
  3. Choose Rank, Ribbons, Medals, or Badges.
  4. Tap an item to place it on the illustrated uniform.
  5. Tap a placed item to remove it.
  6. Use Placement Zones to visualize the general placement areas.
  7. Use the inspection checklist before finalizing your uniform.
  8. Save your setup if you want to come back later.
  9. Print the setup when you're finished.

The visual model is intentionally an illustration rather than an official uniform photograph. Regulations and unit instructions should always control when there is a difference.
